## 一、变量与四种基本类型

```python
name = "张三"     # str  字符串
age = 23          # int  整数
pi = 3.14         # float 浮点数
ok = True          # bool 布尔
```

`type(x)` 查类型。Python 不用声明类型，赋值即创建。

## 二、类型转换

| 目标 | 写法 | 注意 |
|---|---|---|
| 整数 | `int("18")` | `int("3.14")` 会报错，要先 `float` 再 `int` |
| 浮点 | `float("3.14")` | |
| 字符串 | `str(23)` | `+` 拼接时两边必须都是字符串 |
| 布尔 | `bool("abc")` | **非空字符串永远 True**，`bool("False")` 也是 True |

## 三、运算

```python
17 // 5   # 3   整除
17 % 5    # 2   取余
17 ** 5   # 1419857  幂
```

比较 `> < == != >= <=` 的结果就是 `True` / `False`；
`and` 都真才真，`or` 一个真就真，`not` 取反。

## 四、字符串常用方法

| 方法 | 作用 | 例子 |
|---|---|---|
| `upper()` / `lower()` | 全大写 / 全小写 | `"pYtHoN".upper()` → `PYTHON` |
| `strip()` | 去首尾空白 | `"  a  ".strip()` → `a` |
| `split(sep)` | 切成列表 | `"a,b".split(",")` → `['a','b']` |
| `join(lst)` | 拼成字符串 | `"-".join(['a','b'])` → `a-b` |
| `replace(a, b)` | 替换 | 返回新字符串，**必须赋值** |
| `title()` / `capitalize()` | 每词首字母 / 整句首字母大写 | |

**`split()` 不传参 vs 传参**：

```python
"a  b".split()      # ['a', 'b']    按任意空白切，自动丢空片段
"a  b".split(" ")   # ['a','','b']  严格按空格切，连续空格会切出空串
```

## 五、切片

```python
s = "0123456789"
s[2:6]    # 2345    从下标 2 到 5（不含 6）
s[:3]     # 012     前 3 个
s[-3:]    # 789     后 3 个
s[::2]    # 02468   隔一取一
s[::-1]   # 9876543210  反转
```

## 六、f-string

```python
f"{name}今年{age}岁"
f"{3.14159:.2f}"    # 3.14     两位小数
f"{1234567:,}"      # 1,234,567  千分位
f"{0.876:.1%}"      # 87.6%    百分比
f"|{name:<10}|"     # 左对齐占 10 格
f"|{name:^10}|"     # 居中
```

## 七、input

```python
a = float(input("输入一个数: "))
```

```python
if not s.strip():
```

## 八、我的错题（真实踩过）

1. **`b = "Wrold"`** — 拼写错误，输出 `Hello Wrold`。变量值写错不会报错，只会默默输出错的。**写完跑一遍对输出**。
2. **`int("3.14")`** — 直接报 `ValueError`。要先 `float` 再 `int`。
3. **`s.replace(" ", "-")` 没赋值** — 字符串不可变，`replace` 返回新串，不接住就白写。
4. **`sum = a + b`** — 覆盖了内置函数 `sum()`，之后 `sum([1,2,3])` 直接报错。改用 `total`。
5. **`split(" ")` 当 `split()` 用** — 单空格句子碰巧对，多个空格就少算。
6. **中英文标点混用** — 代码里必须半角 `(` `,` `"`，中文内容才用全角 `：`。混用会 `SyntaxError`。
7. 写完代码**全部注释掉** — 等于没跑。代码要跑起来，报错才是反馈。
